# 日文學習平台

直接開啟 `index.html` 即可使用，也可以將此資料夾上傳到 GitHub 並啟用 GitHub Pages。

## 學習規則

- 各階段須累積指定學習時間才能開始該階段的 20 題測驗：階段一 30 小時、階段二 150 小時、階段三 300 小時、階段四 400 小時、階段五 200 小時。僅計入頁面顯示且未作答時的時間。
- 測驗達 85 分才解鎖下一階段；未達標可再次作答。
- 學習時間、通關狀態及錯題存在目前瀏覽器的 `localStorage`，換瀏覽器或清除網站資料會重置。
- 時間門檻由 20 分鐘調整後使用新版進度紀錄，舊版通關紀錄不沿用。
- 錯題本隨時可查看。語音功能需瀏覽器支援語音合成。
- 階段 1～3 點選假名後，會在該排下方顯示範例、讀音與意思，並播放假名發音。下方提示每 30 分鐘嘗試更新網路例句，無法連線時顯示內建提示。
- 點擊右上角開發者按鈕即可暫時解鎖所有階段與測驗；可在開發者選單關閉。重新載入頁面後恢復一般模式。

## 上傳 GitHub

建立新的儲存庫，將 `index.html`、`manifest.webmanifest`、`icon.png`、`icon-192.png`、`icon-512.png`、`README.md` 和 `.gitignore` 放在儲存庫根目錄。若要公開網頁，可在儲存庫 Settings → Pages 選擇從主分支根目錄部署。

## 加到主畫面

先用 HTTPS 網址（例如 GitHub Pages）開啟網站；直接開啟本機 `index.html` 無法提供完整的安裝體驗。Android 可用瀏覽器選單的「安裝應用程式」或「加到主畫面」，iPhone 可用瀏覽器分享選單的「加入主畫面」。安裝後仍需網路載入 CDN 樣式與線上例句。

頁面使用 Tailwind 與 Font Awesome 的 CDN，相關外觀需要網路連線。階段 4 的線上例句無法取得時會使用內建內容。
