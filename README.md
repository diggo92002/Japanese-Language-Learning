# 日文學習平台

直接開啟 `index.html` 即可使用，也可以將此資料夾上傳到 GitHub 並啟用 GitHub Pages。

## 日常生活用語 2,000 句

從首頁開啟 `daily-phrases.html`，或直接開啟該檔案。資料放在 `daily-phrases-data.js`，由五個生活情境各 20 種句型與 20 個相容詞語組合成 2,000 句日中對照例句。可依情境篩選、搜尋日文或中文、每頁閱讀 20 句，也可直接輸入頁碼；瀏覽器會記住篩選條件和最後頁碼。此頁的資料與樣式都在本機，不需例句 API。

## 學習規則

- 所有階段均可直接開啟，隨時開始各階段的 20 題測驗；沒有學習時數門檻。
- 測驗達 85 分會記錄通過狀態；未達標可再次作答，所有階段仍可繼續使用。
- 通關狀態及複習區的題目存在目前瀏覽器的 `localStorage`，換瀏覽器或清除網站資料會重置。
- 階段 4 有 20 句日中對照會話，階段 5 有 14 筆附例句的文法項目。兩個階段每頁顯示 5 筆，可用「上一頁／下一頁」瀏覽；頁碼分開儲存在目前瀏覽器的 `localStorage`，重新開啟會回到上次頁面。階段 4、5 不會呼叫例句 API。
- `common-vocabulary-phase4.js` 和 `common-vocabulary-phase5.js` 各有 2,000 個原始日文詞條，但尚無經校對的中文翻譯、例句或文法資訊，目前不會當作階段 4、5 的學習卡片或測驗答案。新增內容時，階段 4 請提供 `jp`、`tw`、`scenario`；階段 5 請提供 `title`、`formula`、`example`，放入 `index.html` 對應的資料陣列即可自動分頁。
- 複習區隨時可查看測驗中答錯的題目。語音功能需瀏覽器支援語音合成。
- 階段 1～3 首次開啟時只顯示假名。點選假名後，該排下方才會出現常用用語字卡的「核心單字區」與「例句與應用區」；核心單字與讀音會對應目前選取的假名。網路更新功能已停用，字卡使用內建資料。
- 點選假名可播放發音，更新下方常用用語字卡的對應詞彙，並將卡片移到該排下方。階段 1～3 不顯示頂部的內容更新控制。

## 上傳 GitHub

建立新的儲存庫，將 `index.html`、`daily-phrases.html`、`daily-phrases-data.js`、`manifest.webmanifest`、`icon.png`、`icon-192.png`、`icon-512.png`、`README.md` 和 `.gitignore` 放在儲存庫根目錄。若要公開網頁，可在儲存庫 Settings → Pages 選擇從主分支根目錄部署。

## 加到主畫面

先用 HTTPS 網址（例如 GitHub Pages）開啟網站；直接開啟本機 `index.html` 無法提供完整的安裝體驗。Android 可用瀏覽器選單的「安裝應用程式」或「加到主畫面」，iPhone 可用瀏覽器分享選單的「加入主畫面」。安裝後仍需網路載入 CDN 樣式。

頁面使用 Tailwind 與 Font Awesome 的 CDN，相關外觀需要網路連線；學習內容使用本地資料。
